## Summary of changes

- **Settlement on Ethereum instead of Solana.** A chain-neutral `Settlement`
  interface with an Ethereum implementation built on viem. The public API uses
  chain-neutral field names for wallet addresses and transaction hashes.
- **Smart contracts.** `PayoutBatch` (many payouts in one transaction) and
  `Subscriptions` (allowance-based recurring collection), built and tested with
  Foundry, with an Anvil integration test lane for the API.
- **Payouts.** Batched through `PayoutBatch`, built by the API and signed by the
  platform wallet in the dashboard or with the Node SDK; the key never reaches
  the server.
- **Top-ups.** Detected from USDC `Transfer` logs with persisted per-wallet scan
  cursors.
- **Checkout.** Buyers sign an EIP-3009 authorization and a relayer submits it,
  so buyers pay no gas. Hosted checkout signs with browser wallets.
- **Subscriptions.** On-chain plans with capped allowances and renewals
  collected by an operator key; subscription checkout and dashboard pages.
- **Platform wallets.** Up to five wallets per account with safe default
  switching: plan destinations migrate on-chain, prepared checkouts re-prepare,
  and USDC sent to other wallets is flagged.
- **Ledger accuracy.** Each payment is counted once: the top-up scan skips
  transactions recorded as payments, a payment recorded later reverses an
  earlier top-up of the same transaction, and USDC moved between the platform's
  own wallets is credited only for deposits not yet counted.
- **Removed.** The telemetry phone-home, hard-coded upstream hosts and links,
  the unused Anchor program, and upstream screenshots and community links.
- **Brand.** Renamed to FiatDesk with brand tokens in one place (`BRAND`), a
  rebrand script, a new visual identity and updated positioning.
- **Docs.** Product docs, agent skills, README, setup guide, gas and fees guide
  and screenshots rewritten for USDC on Ethereum.
